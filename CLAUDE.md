## Project Overview

This is a machine learning competition entry for **Signate Student Cup 2025**. The task is to predict which two original works (movies/anime/manga) were combined to create LLM-generated mixed synopses. Given 340 fictional synopses generated by mixing elements from 50 base works, the model must identify the correct pair of source works.

**Competition URL**: https://user.competition.signate.jp/ja/competition/detail/?competition=385dcbba17b645f3ac10f827dfba03f6

## Environment and Dependencies

- Do NOT use `pip`, `pip install`, or `python -m pip` directly

```

├── dataset.py                    # Data processing pipeline (CLI with Typer)

├── raw/                          # Original competition data (TSV files)
├── interim/                      # Intermediate transformed data
├── processed/                    # Final canonical datasets for modeling
└── external/                     # Third-party data sources

models/                           # Trained models, checkpoints, predictions

```

## Competition Data Files

Located in `data/raw/`:
- **base_stories.tsv** - 50 source works with id, category, title, and synopsis
- **fiction_stories_practice.tsv** - Practice data (not submitted)
- **fiction_stories_test.tsv** - 340 test synopses for prediction
- **sample_submit.csv** - Submission format with columns `a`, `b` (work IDs)

## Evaluation Metric

**Accuracy**: Both source work IDs must match (order-independent). A prediction is correct only if `{predicted_a, predicted_b}` equals `{actual_a, actual_b}`. Partial matches (only one correct) count as incorrect.

## Code Patterns

### CLI Scripts
All runnable scripts use **Typer** for CLI interfaces:
```python
app = typer.Typer()

@app.command()
def main(arg_path: Path = DEFAULT_PATH):
    logger.info("Processing...")
    # ... code ...
    logger.success("Complete.")

if __name__ == "__main__":
    app()
```

### Logging
Uses **Loguru** with tqdm integration. Logger is configured in `config.py` to write through tqdm progress bars.

### Path Configuration
All paths are centralized in `config.py`:
- `PROJ_ROOT` - Project root directory
- `RAW_DATA_DIR`, `INTERIM_DATA_DIR`, `PROCESSED_DATA_DIR` - Data directories
- `MODELS_DIR` - Model storage
- `REPORTS_DIR`, `FIGURES_DIR` - Output directories
