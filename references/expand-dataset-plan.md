# データ拡張 実装計画

## 目的
- 架空あらすじ生成（合成データ）を作成し、**再ランク学習の補助**に限定して使用する。
- 分布ずれのリスクを最小化する。

## 前提
- 既存ベース作品: 50件
- 架空作品推定タスク（2作品の順不同）
- 生成テンプレは [references/expand-dataset.md](references/expand-dataset.md) を採用

## 1. 生成方針
### 1.1 テンプレート
- 6テンプレート（T0, T1, T2, T3, T5, T6）

### 1.2 生成規模
- 50C2=1,225 × 6テンプレ = 7,350件
- トーン/視点追加（30%サンプル）= 約+2,200件
- 合計 9,500〜10,000件

### 1.3 出力制約
- 320〜420字、1段落、改行禁止
- 固有名詞禁止（人名・地名・作品名・組織名など）
- A/B双方から最低2要素を融合

## 2. 品質担保
### 2.1 自動フィルタ
- 文字数・段落数チェック
- 固有名詞らしき語（中黒/長カタカナ/英字列）検出で再生成
- 入力文との20文字以上の連続一致で再生成
- 埋め込み類似度: `min(simA, simB)` が閾値未満なら再生成

### 2.2 重複排除
- MinHash or Embedding Clusteringで同一文を排除

## 3. 生成データの利用方針
- 再ランク学習にのみ使用
- 合成データ比率は10〜30%に制限

## 4. 実装タスク一覧（生成側）
- 合成生成スクリプト作成
- 品質フィルタ実装
- 重複排除
- 分布・長さ・類似度のサマリ出力

## 5. リスクと対策
- **分布ずれ**: 合成データ比率を抑制し、実データに近い制約を厳守
- **固有名詞混入**: 自動検出＋再生成で対応
